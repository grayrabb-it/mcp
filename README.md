# grayrabb.it MCP

Play Catch the Rabbit from your MCP client.

## Run

```sh
npx -y @thegrayrabbit/mcp
```

Requires Node.js 20 or newer. The server uses standard input and output.

For an MCP client configuration, use command `npx` with arguments `["-y", "@thegrayrabbit/mcp"]`.

Create a local wallet, fund its public address, then read the active hunt and enter. Your wallet keys stay on your device. Entries open when the game is active.

Website and setup: https://grayrabb.it/mcp/
